# Elmsford

埃尔河边的一个小村子，一百五六十口人。河边长着榆树，河上有一处浅浅的渡口，村子就叫这个名字。

那场大瘟疫过去十几年了。几乎每家都死过人，村里还空着几间房子。你是刚搬来的抄写员，租下了墓园边上的那一间，桌子有一条腿短了一截，墙角有点潮。村里没几个人识字，要写信、立契约、念一封远方来的信，都得找你。

这个游戏没有目标，没有谜题，也没有分数。你只是在这里过日子，和这些人慢慢熟起来。

## 村里的人

- **玛蒂尔达**，五十八岁，寡妇，在家酿酒卖酒。嘴快，记仇，谁欠她几便士都记得清清楚楚。
- **托马斯**，磨坊主。话少，做事一丝不苟，可村里人都默认磨坊主会偷斤少两。
- **埃德蒙神父**，二十七岁，书读得多，不知道怎么跟种地的人说话。你那间屋子的钥匙在他手上。
- **琼**，放鹅、帮工，爱拿人打趣。邻村一个有地的鳏夫托人来说亲，她没答应，也没回绝。
- **休伯特**，七十四岁，退下来的老庄头，眼睛快看不清了。他想给四十年没见过面的弟弟写一封信。

他们没有写好的台词，也没有写好的结局。他们记得你说过的话，过些日子会重新提起；会拒绝你，会托你办事，也会自己找上门来。日子久了，有人来，有人走。

## 日子怎么过

开局选一次，之后不能改：

- **按自己的步子**：你不动，日子也不动。一天分上午、下午、晚上，走路、说话、写字都要花时间。累了可以歇一会儿，也可以让一天就这么过去。
- **和你同一天**：村里的日子和你过的是同一天。你不在的时候，他们照样过；你回来时，会先听说这几天出了什么事。

日期、星期、季节都照着真实的历法走。十月秋耕、摘苹果，十一月有万灵节和圣马丁节，冬天日子短，圣诞要过十二天。

## 你能做的

- 在村里走走，到井边、酒馆、磨坊、教堂看看谁在。可以过去说话，也可以在一旁听别人说话。别人家要敲门，屋里黑了就别敲。
- 说话随便说，动作写在星号里，比如 `*把酒杯推过去*`。
- 替人写信。他们口述，你来写，写成什么样由你，反正他们不识字。信每周四随商贩捎走，回信要过好几个星期才到；念给他们听的时候，念什么也由你。
- 记笔记本。关于每个人你知道些什么，都记在这里，你也可以自己补几笔。
- 节日没人给你讲解。你会看见村里在忙什么；问起来，他们会用自己的话告诉你。

全是文字，没有一张图。颜色跟着一天的时辰变，有雨声、风声、流水、炉火，还有教堂的钟。

## 开始玩

需要 Node.js 22 以上和 pnpm。村里的人由 AI 扮演：游戏会直接用你电脑上配好的 Claude Code 或 Codex，也可以在游戏的设置里用 ChatGPT 账号登录，或填一个 DeepSeek 的 key。费用记在你自己的账上。

```bash
pnpm install
pnpm build && pnpm start
```

然后打开 http://127.0.0.1:8787 。

不玩了，想把存档、登录信息和装下的东西都清掉：

```bash
pnpm clean
```

开发相关的说明在 `doc/开发说明.md`。
