# 开发说明

游戏本身的介绍在 `README.md`。这里是怎么跑、代码在哪儿、和设计文档有什么不同。开发约定见 `CLAUDE.md`，设计见本目录下的两份文档。

## 跑起来

```bash
pnpm install
pnpm dev          # 开发：http://127.0.0.1:5173 ，设置 /settings（开发模式下开发者工具也在这一页）
```

```bash
pnpm build && pnpm start        # 正式：http://127.0.0.1:8787 ，单进程，没有开发者工具
pnpm build && pnpm start:lan    # 同上，再加局域网：手机打开终端里打印的带配对码的链接
```

**不用填任何 key。** 服务端直接读本机 Claude Code（`~/.claude/settings.json` 的 `env`）和 Codex（`~/.codex/config.toml` + `auth.json`）的配置；也可以在设置里用 ChatGPT 账号登录，或者填一个 DeepSeek 的 key（这两样存在 `~/.config/elmsford/`）。设置页按档位（对话 / 规划 / 幕后）从接得上的模型里选，每档还能单独设思考程度。可选的环境变量见 `.env.example`。

```bash
pnpm reset        # 只清村子的存档（data/）
pnpm clean        # 清掉 Elmsford 在这台电脑上留下的一切：存档、在设置里接上的账号、依赖、打包出来的文件、.env
pnpm test && pnpm typecheck
```

## 代码地图

```
packages/core       领域逻辑，纯函数，不碰数据库
  clock/            时间、历法、北纬 52° 日出日落、钟声、"圣某某节后第几天"、假时钟
  memory/           记忆检索（近期 + 重要 + 相关度 + 偶尔的旧事回响）
  validator/        校验层：LLM 提出的所有变更都先过这里
  world/            实体类型、作息、天气、导演与摩擦表、新来的人的校验、可复现的随机数
scripts/clean.mjs   pnpm clean：清理脚本，只用 Node 自带的东西
packages/content    种子、地点、作息、历法、气候、摩擦表、物价、还没露面的村里人和外头来的（newcomers.ts）；prompts/ 是全部提示词
apps/server         Hono + SQLite（Drizzle）
  llm/              网关（档位路由、预算、降级、日志）；Claude Code、Codex、ChatGPT 登录、DeepSeek 四种来源；从 CLI 配置读凭据
  conversation/     对话：上下文组装、流式、动作；结束后提取
  sim/              模拟：每日规划、幕后互动、日/周总结、补算引擎、这几天、每周反思、每日规则、有人来（newcomers.ts）、按自己的步子的钟（story.ts）
  scribe/           信件：口述、封缄收费、寄送、远方人物、回信
  world/            仓库（唯一写入世界的地方，入村 addResident、离村和去世 endResident 也在这里）、此刻谁在哪、地点视图
  dev/              风格裁判、模拟玩家
  routes/           player（游戏）、settings（模型）、dev（开发者工具）
apps/web            Vite + React，纯文字界面；设置页（views/Settings）在开发模式下接上 dev/ 的开发者工具
```

一次对话的路径：`routes/player` → `ConversationService` 组装上下文（世界与人物种子在前，可缓存）→ `LlmGateway` 流式调用 → 动作经校验层执行 → 结束后 `extraction` 用便宜模型整理成 `WorldDelta` → `validateAndApply` 决定哪些成为事实。

村子在你不看的时候也照样过：服务端每 30 秒推进一次。离开不到一天逐时推进，一到八天每天一次总结，更久每周一次；每一步都保存进度，可以随时中断、接着补。

## 和设计文档不一样的地方

- **规划和幕后互动是成批调用的**：每天一次调用规划全村、每个时段一次调用处理所有碰面，而不是每人一次。经过中转站时每次调用都有固定开销，成批便宜得多。
- **补算的分界**：不到 26 小时逐时（补的时候 4 小时一段），1 到 8 天按天，超过 8 天按周。
- **M6 做的是本地优先的版本**（见下）。

## 没做的（M6）

- **账号和云存档**：需要一个在线服务和它自己的凭据，跟"只用本机 CLI 的配置"冲突，所以没做。现在的办法：电脑上的服务端就是存档；手机通过局域网配对接进来，玩的是同一个村子。存档导出导入的接口还在（`GET /api/save`、`POST /api/dev/save/import`），界面上不放入口。
- **Capacitor / Tauri 原生包、Steam**：本机没有 Rust 和 Android SDK，没装。PWA 已经可以装到桌面（Chrome/Edge 地址栏的安装按钮，Safari 的"添加到程序坞"）。
- **真正的推送**：手机锁屏也能收到的推送，要走 HTTPS 和推送服务。现在的提醒在页面开着时显示，标签页在后台时用系统通知，每天有上限。
- 手机通过局域网 http 打开时，浏览器不允许 service worker，所以离线外壳和"安装"只在本机（127.0.0.1）可用；手机上可以"添加到主屏幕"。
